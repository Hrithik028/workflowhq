# WorkflowHQ product tour

Published asset: `workflowhq-brag.mp4` — 25 seconds, 1920 × 1080, 30 fps, H.264 video and AAC audio, with fast-start metadata. `workflowhq-brag-poster.jpg` is the settled opening image, also baked into the video's first frame.

## Visuals and provenance

Created locally with the brag workflow and Hyperframes 0.8.138. The opening includes the actual WorkflowHQ built-in demo interface. The remaining ticket movement, development links and AI proposal approval are illustrative animations, not recordings of production mutations, real GitHub events or paid provider calls. The existing longer captioned walkthrough remains available as `workflowhq-demo.mp4`.

## Text overview

- **0–4 seconds:** “Your ticket. Its code.” Actual demo overview and an illustrative WHQ-42 ticket linked to `feature/WHQ-42-webhook-sync`.
- **4–11 seconds:** Ticket planning and movement from Ready to In motion, preserving its acceptance criteria and context.
- **11–17 seconds:** Branch, commit and pull-request evidence linked by the ticket key; status rules remain project-owner controlled.
- **17–22 seconds:** An AI proposal is reviewed before the user approves its application.
- **22–25 seconds:** WorkflowHQ closing card — “Plan the work. Follow the code. Approve the AI.” — with the public application URL.

The tour is a product illustration, not a production integration test or security certification.
